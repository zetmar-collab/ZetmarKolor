Format: 32 x 32 x 32 RGB .cube, DOMAIN 0..1, red changes fastest.
Reference LUTs: Aqua.cube, BW10.cube, Cinematic-5.cube.
Use on normalized, already developed photographic RGB images. These are creative looks,
not camera Log-to-display conversions or automatic white-balance corrections.
Start with 25-50% intensity and adjust to the photograph.
Reference metadata mentions Adobe RGB (1998); .cube files do not embed ICC profiles.
Use consistent input/output color management; sRGB rendering can differ.
Weather and lighting names describe a color mood, not added rain, fog or illumination.
Black and white presets produce neutral equal R/G/B values.
